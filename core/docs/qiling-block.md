# 器灵积木

Created on 2026-11-03; Updated on 2026-11-03  
@author: https://github.com/Linmoqian

左侧「器灵」提供两块可拼接积木：

1. **向「机械臂」载入「器灵」**：选择模型，为当前仿真机械臂载入并命名器灵。
2. **向「器灵」发送「消息」**：选择已载入的器灵，输入文字或连接字符串变量。

连接后点击运行。载入只建立绑定，不调用模型或发送运动。发送消息时调用独立 Agent，器灵在机械臂旁显示处理状态、流式回复与最终回答；气泡跟随机械臂，长内容可滚动、可关闭，片刻后自动收起，并遵守减少动态效果偏好。

同一载入积木对应独立会话和记忆，多块发送消息积木共用该器灵上下文。模型切换沿用这个载入积木的上下文；不同器灵和右侧小虾隔离。程序重跑需再次经过载入积木，消息不能发给尚未载入的器灵。同名再次载入会替换本次程序中的绑定。

程序保存模型、器灵名称、消息与连接。独立会话保存在核心数据目录 `qiling` 子目录。旧版单块器灵仍可加载已有程序。

模型沿用已有 `.env` 服务地址与密钥，选择模型不改写全局默认值。刷新模型读取服务列表，服务不支持列举时仍提供环境中配置的模型；其他模型是否兼容 Responses 接口需以实际请求为准。

后端只注册并允许六个机械臂 MCP：仿真状态、关节限位、六轴显示目标控制、机械臂环境/串口候选查询、相机列表与观察。不提供积木编程、脚本执行和强化学习工具；真实相机只读，当前没有真实电机运动工具。只有明确请求仿真运动时才允许发送目标，accepted 不等于渲染或真机到位。

停止程序会清理器灵和 MCP 子进程。气泡来自真实 Agent 事件，工具结果与历史消息不构成新的动作授权。
