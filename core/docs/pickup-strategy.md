# 抓球强化学习策略（当前 v6）

2026-11-02。目标是在定义的仿真工作区与观测噪声范围内，所有验收回合均成功。旧版35%模型保留作历史基线，不是新版验收结果。

## 旧策略的问题

- 18维状态没有显式任务阶段和双指接触信号，接近/下降/闭爪/抬升阶段的动作标签可能冲突。
- 预训练达到3/5就结束，在线SAC没有执行；最终20轮仅需成功1轮就停止，无法支持可靠性要求。
- 均匀抽样容易让大量移动或等待帧淹没闭爪、抬升、恢复样本。
- Actor和Critic共享视觉编码器，Critic更新可能改变已学会的动作表征；独立行为克隆优化器又与SAC交替修改Actor。

## 分阶段、带约束的学习策略

阶段为搜索、接近、对准、闭爪、抬升、保持、恢复。根据相机可见性、球与夹爪位置差、末端方向、双指接触力、抬升高度和夹爪开度切换。空抓或失抓进入恢复阶段，训练中标注张开/重新接近等纠正动作。

策略输入为腕部64×64 RGB和31维状态：原18维状态，加7维阶段one-hot、2维归一化双指接触力、1维保持进度和3维末端方向误差。仍包含仿真真实球位置及接触信息，不是纯视觉策略。六维关节增量由学习网络输出，阶段控制器不在推理中调用IK。

在未对准时，阶段门控屏蔽负向闭爪指令；闭爪、抬升、保持阶段允许闭爪。门控也固化到ONNX，训练和部署执行同一约束。被屏蔽的提前闭爪请求仍扣分，发现红球、空抓、掉球、时间等奖惩保留；首次进入对准/闭爪/抬升/保持各加0.25分，不允许往返刷分。

## 训练流程

1. 收集覆盖全工作区的64轮成功、按实际阶段切换的示教，并预训练5000次。
2. 三档课程从中心20%跨度、55%跨度扩至完整范围；每档20轮验证全部成功才晋级。最终工作区X为0.16–0.23m，Y为-0.05–0.05m。
3. 必须实际执行在线SAC，默认至少2000次更新，不能通过行为克隆早停绕过。
4. 每批64条转换按阶段均衡抽样，包含32条成功示教、16条在线、16条困难样本（空抓、掉落、碰撞、超时等）；没有困难样本时从在线回放补足。
5. Actor和Critic使用独立编码器；Actor的SAC损失与0.5倍示教约束在同一次梯度更新中计算。每1000次预训练/200次在线更新保存权重。
6. 独立验证退步时保留最优候选；连续3次未改善可恢复最优权重并清除优化器动量。失败后的纠正样本只用于行为克隆，混合专家执行不计入模型成功率，也不伪造SAC转换。

## 100%验收规则

候选导出ONNX后，在全范围分别执行100个随机位置、100个带观测噪声的随机位置，以及7×5网格的35个位置（包括边界）。全部235轮成功才能将task_success_validated和robust_grasp_validated标为true。任何一轮失败即不通过，记录结果后继续训练，不能换种子抹掉失败批次。

成功仍要求双指真实力接触、红球无地面支撑、抬升至少5cm并持续1秒；回合内非底座机械臂接地力超过5N也不接受为成功。这里的碰撞条件只覆盖已实现的接地检查，不等于完整自碰撞验收。100%只指这组明确范围的有限测试，不保证未测试场景或实机成功率。

## 接口和运行

现有ball-trainings积木/API入口保持不变。当前环境版本为so101_pickup_v6_stable_sac；旧18维权重与示教不能接续新版训练。ONNX-predictions根据manifest要求31维原始状态，缩放在ONNX内部完成；旧18维ONNX仍可单独做数值预测，但不能在新版环境执行有效rollout。

onnx-rollouts新增suite=clean/noisy/grid，grid固定35轮；train_ball可指定minimum_online_updates（500–100000，默认2000）。持续训练脚本为core/scripts/train_ball_until_success.py，报告写入core/data/runtime/pickup-campaign.json。

本次有限检查已通过：新参考控制完成44步物理抓取；31维行为克隆、带示教约束的SAC更新、带阶段门控的ONNX导出与推理通过，导出最大数值误差约2.31e-7。尚未取得新版235/235结果，不能宣称100%已实现。未改动前端，未构建桌面或操作实机。

训练结构参考[LeRobot HIL-SERL工作流](https://huggingface.co/docs/lerobot/hilserl)的示教、在线SAC和干预思路；本项目使用仿真专家纠正与物理成功判定，不等于官方完整实机HIL-SERL方案。


## v6 针对悬停与在线退步的优化

旧v5运行到约71000次更新、3059回合时仍停留课程0，最近独立验证0/20，其中19轮停在align；复算五个终态，球与夹爪距离约6.87–7.09cm、方向误差约0.166–0.180，说明主要问题是悬停而非成功抬起后掉落。

环境版本更新为so101_pickup_v6_stable_sac，奖励版本pickup_v5_progress；旧权重/旧奖励轨迹不直接接续。靠近进展系数5→25，新增方向改善奖励、接近/对准无进展惩罚，以及每指每回合一次的首次接触奖励。相同条件下7cm处悬停单步约-0.04，下降2mm约+0.04；不改变真实成功判定。末端方向误差输入额外缩放5倍。

预训练选择验证表现最好的权重，而非直接使用最后一次更新。先用示教做1000次Critic预热，Actor不更新；在线Actor学习率3e-5、Critic3e-4、温度1e-4，Actor每两个Critic更新一次，探索标准差上限0.05，温度初值0.001。Actor的SAC损失按其停止梯度后的绝对值归一化，再叠加10倍示教锚定，避免Q值增长压过示教约束。回滚基线包含预热后的Critic，不回到随机Q网络。

连续六次在线验证零成功（默认500次更新检查一次）即结束当前停滞批次，保留最优模型并进入下一批更大示教/预训练；未达到候选条件不执行235轮最终验收，也不标为成功。逐次在线评估结果保存在任务evaluations目录，增加最近距离、最大抬升、各阶段步数与失败阶段记录。235/235验收条件保持不变。

有限检查覆盖Critic单独更新时Actor权重不变、带强示教约束的SAC更新损失为有限值，以及悬停/下降奖励方向。优化效果需由新训练验证，尚不能报告新成功率。

每批在线更新上限10000次，未通过候选验证就进入下一批增加示教与预训练，整体235/235目标不变。
