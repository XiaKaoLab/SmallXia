# Sim2Real 一期：器灵关节动作

Created on 2026-11-03; Updated on 2026-11-03  
@author: https://github.com/Linmoqian

器灵可绑定仿真或指定 COM 口。左侧「器灵」新增「Sim2Real 预检」；载入真机时显示配置和「启用运动」选项，默认只读。可以依次拼接预检、载入和发送消息。

预检只检查文件和现有控制会话，不打开串口，不写电机、不使能力矩。需要官方校准、已确认的六轴编码器零点及方向、匹配的串口与 URDF、最高 0.15 rad/s 的配置。显示对齐配置不能替代运动坐标验证。

显式启用后复用硬件控制连接，连接时检查 EEPROM 校准与电机模式。每条消息最多尝试一次六轴目标，各轴相对新鲜实测位置最多变化 10°；必须通过关节限位和碰撞检查。目标单位为 rad；到位以实际反馈判断，超时停止，不自动重试。程序保持控制心跳，停止或失联由现有释放机制处理。界面只用新鲜真机反馈更新跟随模型，并标记来源。

API 均为 POST，沿用现有服务鉴权：

- `/api/v1/sim2real/checks`：`port`、`profile`，返回坐标预检及阻塞原因。
- `/api/v1/sim2real/state`：相同参数，返回实测来源、关节状态和预检。
- `/api/v1/sim2real/motions`：额外传入 `enable_motion: true`、`unit: "rad"` 和完整六轴 `joint_positions`；接收不代表到位。

2026-11-03 验证：通过实际积木运行完成 COM17 预检、只读载入及器灵查询。官方校准存在，但控制映射的六轴 zero_tick、direction 缺失且 verified=false，因此正确阻止运动。本轮没有打开电机控制连接或执行实机动作；实机坐标、限速和到位验证尚未完成。本阶段不包含抓取策略的 Sim2Real。


## 简化坐标标定 API

基地址 `/api/v1/sim2real/calibrations`，沿用服务鉴权。只测量控制坐标，不写电机 EEPROM、不改动力矩。操作者仍需确认姿态与正方向；接口不会从极限中值猜测零点。

| 请求 | 参数 | 用途 |
| --- | --- | --- |
| POST 基地址 | `port: "COM17", profile: "so100.local.yaml"` | 创建会话，返回 id、zero 步骤与六轴零位参考 |
| GET `/{id}` | 无 | 获取当前步骤 |
| POST `/{id}/sample` | `{}`，点击操作即表示确认当前姿态/方向 | 自动读12帧、取中值并计算；成功后推进下一轴 |
| POST `/{id}/save` | `{}` | 完成六轴后校验并原子保存，保留旧映射备份 |
| POST `/{id}/cancel` | `{}` | 取消未保存会话，不改动已有映射 |

界面只需按 `stage` 显示操作，使用 `reference_rad` 展示参考模型，以 `joint` 突出当前轴，显示 `instruction`。zero → direction（六轴自动推进）→ review → saved。保存返回 `close_panel: true`。每次方向采样从本轴零位向仿真正方向移动；reference_rad 显示10度参考，其他轴为零。返回的 reference_rad 是显示数据，接口不会发送到真机。

采样取中值并返回波动信息，不以固定波动阈值拦截。接口同步采样，轮询请求不能并发。每次释放串口；配置/官方校准改变、EEPROM不匹配、力矩开启或已有控制会话时拒绝采样。会话不再因等待超时失效，允许中断后继续；方向采样取消固定幅度范围，只有没有刻度变化时提示继续转动。保存仍需完整六轴数据。缺少官方校准时应转入现有官方校准流程。

2026-11-04 联调：实际 HTTP 创建/查询/取消成功；缺少姿态确认、提前保存和取消后采样返回422。COM17 只读12帧采样成功，从 zero 推进 direction；诊断会话随后取消，原控制映射未改变、未写电机。发现配置引用旧官方校准，已改为与设备 EEPROM 完全匹配的现有文件 xiaoxia_COM17_cc6356e7d58b.json。

隔离临时目录用明确标注的软件输入跑通六轴正负方向、review、save、备份及 close_panel；不代表真实方向已确认。真实六轴方向和保存尚未完成。API 尚未接入前端专用面板。首次采样会加载电机库，调用方建议使用40秒超时；超时后先查询会话状态，勿盲目重复 sample。


## 从积木完成映射

机械臂分类新增「校准关节映射 COM口」，独立运行以避免后续积木提前执行。运行后顶部胶囊面板自动打开，仿真显示参考姿态。操作者只需按「已对齐」记录零点，逐轴跟随10度参考并按「已转动」，最后按「保存」。错误保留当前步骤，可重新操作；取消不改变映射。保存后自动关闭并提示「已保存」，随后开启现有只读真机到仿真跟随。以后「映射真机到仿真」积木优先使用已确认且匹配设备校准的实测零点/方向，不叠加旧显示腕部偏移。

2026-11-04：通过实际 Tauri 积木运行按钮验证生成 Python → 后台创建会话 → 回执打开胶囊面板 → 原生桥读取会话并设置仿真参考姿态。未代替操作者点击姿态/方向确认，未保存实机映射。验证后恢复原工作区，未覆盖保存槽。

2026-11-04：按要求移除校准会话30分钟过期、24刻度抖动拦截和35–350刻度转动幅度限制。界面错误后显示「重试」，重试原操作，不再混用确认按钮。

2026-11-04 交互简化：点击采样/保存本身即为确认，不要求重复传入确认标志；重新运行积木直接切换新会话并清理旧会话，不要求先取消。保存复用已完成的测量，不再额外打开串口重复采样。已停止的历史控制会话不再阻止采样。前端统一使用简短错误提示，旧请求返回不会覆盖新会话。


## COM 位置积木运行与拖动

完成实测映射后，单独运行「机械臂 COM17」位置积木会自动连接真机、发送当前姿态并保持控制，无需另拼连接积木。运行期间拖动滑条，将合并发送最新六轴目标，并以真机反馈更新模型；停止程序释放控制。位置积木接入多步程序时自动连接并依次等待到位，程序结束释放。

映射缺失时运行直接提示「请先完成关节映射」，不会打开电机控制。2026-11-04 已在实际界面验证此失败路径；自动连接、实时滑条发送和控制反馈已接入，真实运动验收仍需完成六轴映射。未把缺失数据填为默认值。

2026-11-04 闭环：单独运行 COM 位置积木若缺少映射，任务自动创建 resume_control 校准会话并打开积木向导，等待操作者完成后继续连接与控制，不要求再次运行。取消/停止结束等待；保存后不再并行启动只读串口跟随，避免抢占控制串口。此链路仍需真实操作者完成姿态和六轴方向，未用假数据冒充实测。

应用 Agent 提供 arm_mapping_status、arm_mapping_step、arm_mapping_save，接管已有积木会话。采样需依据当前实机姿态/方向确认，不能把泛泛授权或仿真画面视为实测依据。保存后已有任务自动继续控制。
