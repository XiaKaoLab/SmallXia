SO-100

在以下步骤中，我们将说明如何组装 SO-100 机器人。

采购零件

请参考此 README。它包含了物料清单、零件采购链接以及 3D 打印零件的说明。如果您是第一次打印或者没有 3D 打印机，请查看相关建议。

安装 LeRobot 🤗

要安装 LeRobot，请参考我们的 安装指南

除了这些说明外，您还需要安装 Feetech SDK

pip install -e ".[feetech]"

配置电机

注意： 与 SO-101 不同，机械臂组装完成后，电机连接器不易触及，因此配置步骤必须预先完成。

1. 查找每个机械臂对应的 USB 端口

要查找每个总线伺服适配器的端口，请运行此脚本

lerobot-find-port
Mac
Linux

示例输出

Finding all available ports for the MotorBus.
['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
Remove the USB cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/tty.usbmodem575E0032081
Reconnect the USB cable.

找到的端口是： /dev/tty.usbmodem575E0032081，对应于您的主控臂或从动臂。

2. 设置电机的 ID 和波特率

每个电机在总线上都有唯一的 ID。当电机是全新的时，它们的默认 ID 通常是1。为了让电机和控制器之间正常通信，我们需要为每个电机设置一个唯一的、不同的 ID。此外，总线上数据传输的速度由波特率决定。为了相互通信，控制器和所有电机都需要配置相同的波特率。

为此，我们首先需要单独连接每个电机和控制器来设置这些参数。由于我们会将这些参数写入电机内部存储器的非易失性部分（EEPROM），所以我们只需要做一次。

如果您正在重新利用来自另一个机器人的电机，您可能也需要执行此步骤，因为 ID 和波特率可能不匹配。

跟随者

将电脑的 USB 线和电源连接到从动臂的控制板。然后，运行以下命令，或者使用上一步获取的端口运行 API 示例。您还需要使用 id 参数为您的主动臂命名。

有关如何设置电机 ID 的视觉参考，请参阅 此视频，其中演示了 SO101 机械臂的操作流程。

命令
API 示例
lerobot-setup-motors \
    --robot.type=so100_follower \
    --robot.port=/dev/tty.usbmodem585A0076841  # <- paste here the port found at previous step

您应该会看到以下指令

Connect the controller board to the 'gripper' motor only and press enter.

按照指示，连接夹爪电机。请确保它是唯一连接到板上的电机，并且电机本身尚未与其他电机级联。当您按下 [Enter] 时，脚本将自动为该电机设置 ID 和波特率。

故障排除

如果此时出现错误，请检查您的电缆并确保它们已正确插入。

  • 电源
  • 电脑和控制器板之间的 USB 电缆
  • 从控制器板到电机的 3 针电缆

如果您使用的是 Waveshare 控制器板，请确保两个跳线都设置在 B 通道（USB）上。

然后您应该看到以下消息

'gripper' motor id set to 6

接着是下一条指令

Connect the controller board to the 'wrist_roll' motor only and press enter.

您可以断开控制板上的 3 针线缆，但可以保持其另一端与夹持器电机的连接，因为它已经处于正确的位置。现在，将另一根 3 针线缆插入手腕旋转电机并连接到控制板。与之前的电机一样，请确保它是连接到控制板的唯一电机，并且电机本身没有连接到任何其他电机。

按照指示为每个电机重复此操作。

在按 Enter 键之前，请在每一步检查您的布线。例如，在操作电路板时，电源线可能会断开。

完成后，脚本将自动完成，此时电机就可以使用了。现在您可以将每个电机的三线电缆连接到下一个电机，并将第一根电机（ID=1 的“肩部旋转”）的电缆连接到控制器板，控制器板现在可以安装在机械臂的底部。

领导者

对主动臂执行相同的步骤。

命令
API 示例
lerobot-setup-motors \
    --teleop.type=so100_leader \
    --teleop.port=/dev/tty.usbmodem575E0031751  # <- paste here the port found at previous step

逐步组装说明

移除 6 个主动电机的齿轮

移除齿轮的视频

按照视频操作移除齿轮。您需要移除主动臂电机的齿轮。这样，您将仅使用电机的位置编码并减少摩擦，从而更轻松地操作主动臂。

清理零件

移除 3D 打印零件上的所有支撑材料。最简单的方法是使用小螺丝刀撬到支撑材料下方。

额外指导

机械臂组装视频

注意： 此视频提供了组装机械臂的视觉指导，但未具体说明何时或如何进行布线。预先插入线缆比事后操作要容易得多。组装第一个机械臂可能需要 1 个多小时，但一旦熟练后，组装第二个机械臂可在 1 小时内完成。

第一个电机

第 2 步：插入电线

  • 在第一个电机中插入两根电线。

第 3 步：安装到基座

  • 将第一个电机放入基座。

第 4 步：固定电机

  • 用 4 颗螺丝固定电机。底部两颗，顶部两颗。

第 5 步：安装电机支架

  • 套入第一个电机支架，并使用两颗螺丝（每侧一颗）将其固定。

第 6 步：安装舵盘

  • 安装两个舵盘，用螺丝固定顶部舵盘。安装舵盘时尽量不要移动电机位置，特别是对于移除了齿轮的主动臂。
添加舵盘的视频

第 7 步：安装肩部零件

  • 将一根电线引向机器人背部，另一根引向左侧或朝向您的方向（见照片）。
  • 安装肩部零件。

第 8 步：固定肩部

  • 用顶部 4 颗和底部 4 颗螺丝拧紧肩部零件 （通过旋转肩部来对准底部孔洞）。

第二个电机组装

第 9 步：安装电机 2

  • 从顶部滑入第二个电机，并将电机 1 的电线连接到电机 2。

第 10 步：安装肩部支架

  • 添加肩部电机支架。
  • 确保从电机 1 到电机 2 的电线位于支架后面，而另一根电线向上引出（见照片）。
  • 这个零件组装时可能比较紧，您可以像图片中那样使用工作台或类似的装置来将零件推入电机周围。

第 11 步：固定电机 2

  • 用 4 颗螺丝固定第二个电机。

第 12 步：安装舵盘

  • 将两个舵盘安装到电机 2 上，同样使用舵盘螺丝。

第 13 步：安装基座

  • 使用 2 颗螺丝安装基座连接件。

第 14 步：安装大臂

  • 每侧使用 4 颗螺丝安装大臂（上臂）。

第三个电机组装

第 15 步：安装电机 3

  • 将电机 2 的电机电缆通过线缆支架引导至电机 3，然后用 4 颗螺丝固定电机 3。

第 16 步：安装舵盘

  • 将两个舵盘安装到电机 3 上，再次用舵盘螺丝固定其中一个。

第 17 步：安装小臂

  • 每侧使用 4 颗螺丝将小臂（前臂）连接到电机 3。

第四个电机组装

第 18 步：安装电机 4

  • 滑入电机 4，连接来自电机 3 的电缆，并用螺丝将电缆固定在支架中。

第 19 步：安装电机支架 4

  • 安装第四个电机支架（配合较紧）。确保一根电线向上引导，来自电机 3 的电线向下引导（见照片）。

第 20 步：固定电机 4 并安装舵盘

  • 用 4 颗螺丝固定电机 4 并安装其舵盘，其中一个使用舵盘螺丝。

手腕组装

第 21 步：安装电机 5

  • 将电机 5 插入手腕支架，并用 2 颗正面螺丝固定。

第 22 步：安装手腕

  • 将电机 4 的电线连接到电机 5。并提前插入夹持器的另一根电线。
  • 每侧使用 4 颗螺丝将手腕固定到电机 4 上。

第 23 步：安装手腕舵盘

  • 在手腕电机上仅安装一个舵盘，并用舵盘螺丝固定。

从动臂配置

第 24 步：安装夹持器

  • 将夹持器连接到电机 5。

第 25 步：安装夹持器电机

  • 插入夹持器电机，连接从电机 5 到电机 6 的电机电线，并每侧用 3 颗螺丝固定。

第 26 步：安装夹持器舵盘和爪子

  • 安装舵盘，再次使用舵盘螺丝。
  • 安装夹持器爪子，并每侧使用 4 颗螺丝固定。

第 27 步：安装控制器

  • 将电机控制器安装到机器人背部。

组装完成 – 请继续进行主动臂组装。

主动臂配置

对于主动臂配置，请执行 第 1-23 步。请确保您已从电机中移除了电机齿轮。

第 24 步：安装主动臂支架

  • 将主动臂支架安装到手腕上并用螺丝固定。

第 25 步：安装手柄

  • 使用 4 颗螺丝将手柄连接到电机 5。

第 26 步：安装夹持器电机

  • 插入夹持器电机，每侧用 3 颗螺丝固定，使用舵盘螺丝安装一个舵盘，并连接电机线。

第 27 步：安装扳机

  • 使用 4 颗螺丝安装控制从动臂的扳机。

第 28 步：安装控制器

  • 将电机控制器安装到机器人背部。

校准

接下来，您需要校准机器人，以确保领导者和跟随者机械臂在物理位置相同时具有相同的姿态值。校准过程非常重要，因为它允许在一个机器人上训练的神经网络在另一个机器人上也能正常工作。

跟随者

运行以下命令或 API 示例来校准从动臂

命令
API 示例
lerobot-calibrate \
    --robot.type=so100_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \ # <- The port of your robot
    --robot.id=my_awesome_follower_arm # <- Give the robot a unique name

我们统一了大多数机器人的校准方法。因此，此 SO100 机械臂的校准步骤与 Koch 和 SO101 的步骤相同。首先，我们必须将机器人移动到每个关节处于其活动范围中间的位置，然后按下 Enter。其次，我们将所有关节在其完整的运动范围内移动。有关 SO101 相同过程的参考视频可以在 此处 找到。

领导者

执行相同的步骤来校准主控臂，运行以下命令或 API 示例

命令
API 示例
lerobot-calibrate \
    --teleop.type=so100_leader \
    --teleop.port=/dev/tty.usbmodem58760431551 \ # <- The port of your robot
    --teleop.id=my_awesome_leader_arm # <- Give the robot a unique name
