π₀.₅ (Pi05) 策略

π₀.₅ 是来自 Physical Intelligence 的一款具有开放世界泛化能力的视觉-语言-动作模型。其 LeRobot 实现版本改编自他们开源的 OpenPI 仓库。

模型概述

π₀.₅ 是 π₀ 的重要演进版本，由 Physical Intelligence 开发，旨在解决机器人领域的一个重大挑战：开放世界泛化。虽然机器人可以在受控环境中执行出色的任务，但 π₀.₅ 旨在泛化到训练期间从未见过的全新环境和场景中。

泛化挑战

正如 Physical Intelligence 所解释的，根本挑战不在于执行敏捷或灵巧的任务，而在于泛化能力，即在新的环境中使用新物体正确执行任务的能力。考虑一个清洁不同家庭的机器人：每个家庭在不同位置都有不同的物体。泛化必须在多个层面实现：

  • 物理层面：理解如何拿起勺子（握住手柄）或盘子（握住边缘），即使在杂乱环境中面对未见过的物体也能做到。
  • 语义层面：理解任务语义，例如将衣服和鞋子放在哪里（洗衣篮，而不是床上），以及什么工具适合清理溢出物。
  • 环境层面：适应“混乱”的现实世界环境，如家庭、杂货店、办公室和医院。

基于异构数据的协同训练

π₀.₅ 的突破性创新在于在异构数据源上进行协同训练。模型学习内容包括：

  1. 多模态网络数据：图像标注、视觉问答、物体检测。
  2. 语言指令：人类逐步指导机器人完成复杂任务。
  3. 子任务命令：高层语义行为标签（例如，针对未铺好的床执行“拿起枕头”）。
  4. 跨具身机器人数据：来自不同能力和平台的各种机器人数据。
  5. 多环境数据：部署在许多不同家庭中的静态机器人数据。
  6. 移动操作数据：约 400 小时的移动机器人演示。

这种多样化的训练组合创造了一种“课程”，使得模型能够同时在物理、视觉和语义层面实现泛化。

安装要求

  1. 请遵循我们的安装指南来安装 LeRobot。

  2. 运行以下命令安装 Pi0.5 依赖项：

    pip install -e ".[pi]"

用法

要在您的 LeRobot 配置中使用 π₀.₅，请将策略类型指定为：

policy.type=pi05

训练

训练命令示例

以下是用于在您自己的数据集上微调基础 π₀.₅ 模型的完整训练命令：

lerobot-train \
    --dataset.repo_id=your_dataset \
    --policy.type=pi05 \
    --output_dir=./outputs/pi05_training \
    --job_name=pi05_training \
    --policy.repo_id=your_repo_id \
    --policy.pretrained_path=lerobot/pi05_base \
    --policy.compile_model=true \
    --policy.gradient_checkpointing=true \
    --wandb.enable=true \
    --policy.dtype=bfloat16 \
    --policy.freeze_vision_encoder=false \
    --policy.train_expert_only=false \
    --steps=3000 \
    --policy.device=cuda \
    --batch_size=32

关键训练参数

  • --policy.compile_model=true：启用模型编译以加快训练速度。
  • --policy.gradient_checkpointing=true：在训练期间显著减少内存使用。
  • --policy.dtype=bfloat16：使用混合精度训练以提高效率。
  • --batch_size=32：训练批次大小，请根据您的 GPU 显存进行调整。
  • --policy.pretrained_path=lerobot/pi05_base：您想要微调的基础 π₀.₅ 模型，选项包括：
    • lerobot/pi05_base
    • lerobot/pi05_libero （专门在 Libero 数据集上训练的版本）

训练参数详解

参数 默认 描述
freeze_vision_encoder false 不要冻结视觉编码器
train_expert_only false 不要冻结 VLM，训练所有参数

💡 提示：设置 train_expert_only=true 可以冻结 VLM 并仅训练动作专家（Action Expert）和投影层，从而在减少内存占用的情况下进行微调。

如果您的数据集未使用 quantiles 进行转换，可以使用以下命令进行转换：

python src/lerobot/datasets/v30/augment_dataset_quantile_stats.py \
    --repo-id=your_dataset \

或者使用以下归一化映射训练 pi05： --policy.normalization_mapping='{"ACTION": "MEAN_STD", "STATE": "MEAN_STD", "VISUAL": "IDENTITY"}'

相对动作

默认情况下，π₀.₅ 预测绝对动作。您可以启用相对动作，让模型预测相对于当前机器人状态的偏移量。这可以提高某些设置下的训练稳定性。

要使用相对动作，首先通过 CLI 在相对空间中重新计算您的数据集统计信息：

lerobot-edit-dataset \
    --repo_id your_dataset \
    --operation.type recompute_stats \
    --operation.relative_action true \
    --operation.chunk_size 50 \
    --operation.relative_exclude_joints "['gripper']" \
    --push_to_hub true

或者在 Python 中执行等效操作：

from lerobot.datasets.lerobot_dataset import LeRobotDataset
from lerobot.datasets.dataset_tools import recompute_stats

dataset = LeRobotDataset("your_dataset")
recompute_stats(dataset, relative_action=True, chunk_size=50, relative_exclude_joints=["gripper"])
dataset.push_to_hub()

chunk_size 应与您的策略 chunk_size 相匹配（π₀.₅ 默认为 50）。relative_exclude_joints 列出了应保持在绝对空间中的关节名称（例如夹爪命令）。使用 --push_to_hub true 将更新后的统计信息上传到 Hub。

然后开启相对动作进行训练：

lerobot-train \
    --dataset.repo_id=your_dataset \
    --policy.type=pi05 \
    --policy.use_relative_actions=true \
    --policy.relative_exclude_joints='["gripper"]' \
    ...

性能结果

Libero 基准测试结果

π₀.₅ 在 Libero 基准测试套件中表现出强大的性能。为了比较和测试其 LeRobot 实现，我们在 Libero 数据集上对 libero 基础模型进行了额外的 6k 步微调，并将结果与 OpenPI 的参考结果进行了对比。

基准测试 LeRobot 实现 OpenPI 参考
Libero Spatial 97.0% 98.8%
Libero Object 99.0% 98.2%
Libero Goal 98.0% 98.0%
Libero 10 96.0% 92.4%
平均分 97.5% 96.85%

这些结果证明了 π₀.₅ 在各种机器人操作任务中具有强大的泛化能力。要复现这些结果，您可以按照 Libero 部分中的说明进行操作。
