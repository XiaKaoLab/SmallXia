# 器灵积木

Created on 2026-11-03; Updated on 2026-11-03  
@author: https://github.com/Linmoqian

左侧「器灵」分类提供独立 Agent 积木。模型、消息和回复都位于积木内，器灵不占用右侧「小虾」对话栏。

1. 拖入器灵积木，在模型下拉框选择服务提供的模型，或使用当前默认模型。
2. 在「消息」输入文本，也可连接字符串变量。
3. 点击程序运行，执行到器灵积木时发送消息；回复显示在积木的「回复」行，悬停可查看完整内容。
4. 器灵积木有前后连接，可以拼接等待、机械臂或其他器灵积木。

每块器灵积木以自身 ID 对应独立 SQLite 会话与记忆，模型切换沿用该块积木的上下文，和右侧小虾及其他器灵积木隔离。程序保存包含模型、消息、连接与最近回复；会话保存在核心数据目录的 `qiling` 子目录。复制积木生成新 ID 后建立新上下文。

模型沿用已有 `.env` 服务地址与密钥，选择模型不会改写全局默认值。刷新模型读取服务列表，服务不支持列举时仍提供环境中配置的模型。服务列出的其他模型是否兼容当前 Responses 接口需以实际请求为准。

后端采用独立 MCP 配置，只注册并允许以下六个工具：

- 仿真机械臂状态、关节限位与六轴目标控制。
- 机械臂环境/串口候选查询、相机列表及真实/仿真观察。

不提供积木编程、脚本执行、强化学习工具，也没有真实电机运动工具。器灵可在多轮工具调用后回复；缺少目标信息时提出问题，用户可修改消息后再运行。停止程序会结束器灵子进程及其 MCP 子进程。

已完成默认模型的真实 API 调用，器灵成功通过 MCP 读取仿真状态并返回回复；验证六工具白名单，非机械臂工具被拒绝。未为此执行构建或真实机械臂运动。
